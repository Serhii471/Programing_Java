# JDBC-драйвер

У цій папці використовується офіційний драйвер `sqlite-jdbc-3.53.4.0.jar` проєкту Xerial.

- Проєкт: https://github.com/xerial/sqlite-jdbc
- Версія: `3.53.4.0`
- Ліцензія: Apache License 2.0
- Джерело завантаження: Maven Central
- SHA-256: `bcb1f51e36f940867e83342f9efbf5968ac44a6bef4d397bb4af7b17b45cd2fb`

Драйвер містить Java-класи JDBC та нативні бібліотеки SQLite для основних операційних систем.
Контрольну суму звірено з офіційним файлом `checksums_sha256.txt`, який також збережено в цій папці.
