## 1. Теоретична частина

### 1.1. Що таке масив?

Масив - це структура даних фіксованого розміру, яка зберігає впорядковану послідовність елементів одного типу. Кожен елемент має індекс, за яким до нього можна звернутися. У Java масив є об'єктом.

### 1.2. Який індекс 5-го за порядком елемента лінійного масиву?

Індекс п'ятого елемента дорівнює **4**, тому що нумерація елементів масиву в Java починається з нуля: `0, 1, 2, 3, 4`.

### 1.3. Як можна визначити розмір масиву?

- Під час створення масиву розмір задають у квадратних дужках: `new FinancialInstitution[10]`.
- Під час ініціалізації переліченням розмір визначається кількістю елементів: `new int[] {1, 2, 3}`.
- Довжину вже створеного масиву отримують через поле `length`, наприклад: `institutions.length`.

Після створення змінити довжину звичайного масиву не можна. Для динамічної кількості елементів використовують колекції, наприклад `ArrayList`.

### 1.4. Якого типу можуть бути елементи масиву?

Елементи масиву можуть мати будь-який один тип:

- примітивний: `int`, `double`, `boolean`, `char` тощо;
- посилальний: об'єкти класів, рядки, інші масиви, значення типу інтерфейсу або перелічення.

Усі елементи конкретного масиву мають бути сумісними з типом, оголошеним для цього масиву.

## 2. Практична частина

Створено клас `FinancialInstitution` з полями:

- `name` - назва фінансової установи;
- `licenseCode` - код ліцензії;
- `baseCapital` - базовий капітал у гривнях.

Клас `FinancialInstitutionRegistry` агрегує масив `FinancialInstitution[]` і містить окремі методи для всіх потрібних операцій:

- `printAll(...)` - виведення всього масиву з індексами;
- `update(...)` - модифікація вибраного елемента;
- `printWithCapitalAtLeast(...)` - фільтрація установ за умовою `baseCapital >= 15 000 000`;
- `sortByCapitalAscending()` - сортування за зростанням капіталу;
- `sortByCapitalDescending()` - сортування за спаданням капіталу.

Початковий масив містить **10 фінансових установ**. Користувач вводить індекс установи та нові значення всіх її полів. Перед зміною перевіряються межі індексу, непорожність текстових полів і коректність капіталу.

## 3. Запуск програми

Відкрийте термінал у папці `Lab8` і виконайте:

```powershell
cd src
javac -encoding UTF-8 Main.java
java Main
```

Приклад даних для перевірки модифікації:

```text
2
Нова страхова компанія
LIC-NEW-2026
27500000
```

Після введення програма:

1. покаже оновлений масив;
2. виведе установи з капіталом не менше 15 млн грн;
3. відсортує масив за зростанням капіталу;
4. відсортує масив за спаданням капіталу.
