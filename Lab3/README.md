# Лабораторна робота №3 — Програмування Java

## Варіант 14

### Завдання
1. **Теоретична частина:** Відповіді на питання про виняткові ситуації (exceptions) у Java: `try-catch`, множинні `catch` блоки, призначення `finally`.
2. **Практична частина:** Доповнення програми з попередньої лабораторної. Додано перехоплення виняткових ситуацій за допомогою конструкції `try-catch-finally`, щоб некоректне введення користувачем значення `x` (наприклад, введення тексту замість числа) оброблялося як виняткова ситуація.

### Як запустити
```bash
cd src
javac Main.java
java Main
```
