# Лабораторна робота №10 - Програмування Java

## Тема: Робота з текстовими та двійковими файлами
## Варіант 14: Фінансова установа

---

## 1. Завдання

Програму з ЛР9 доповнено можливостями:

1. зчитування даних про фінансові установи з текстового UTF-8 файла в масив об'єктів;
2. запис відсортованого масиву у нетекстовий двійковий файл;
3. зчитування двійкового файла і відтворення відновлених об'єктів на екрані.

Усі операції ЛР8 і ЛР9 збережено.

---

## 2. Формат текстового файла

Вхідні дані розташовані у `data/institutions.txt`. Файл можна створювати й редагувати у програмі «Блокнот», зберігаючи його в кодуванні UTF-8.

Кожен непорожній рядок містить три поля, відокремлені крапкою з комою:

```text
назва;код ліцензії;базовий капітал
```

Приклад:

```text
АгроПромінвест Банк;LIC-140514;25000000
```

Рядки, які починаються із символу `#`, є коментарями. Для дробової частини капіталу допускається крапка або кома.

Метод `readTextFile(...)`:

- відкриває файл через `BufferedReader` у кодуванні UTF-8;
- перевіряє кількість полів і числове значення капіталу;
- створює об'єкти `FinancialInstitution`;
- формує з них агрегований масив `FinancialInstitution[]`.

---

## 3. Формат нетекстового файла

Після виконання операцій ЛР9 масив ще раз сортується за назвою та записується у `data/institutions.dat`.

Для запису використано `DataOutputStream`. Структура файла:

1. кількість об'єктів типу `int`;
2. для кожного об'єкта:
   - назва через `writeUTF(...)`;
   - код ліцензії через `writeUTF(...)`;
   - базовий капітал через `writeDouble(...)`.

Метод `readBinaryFile(...)` використовує `DataInputStream`, читає дані в такому самому порядку, відновлює масив об'єктів і повертає новий `FinancialInstitutionRegistry`.

---

## 4. Запуск програми

Відкрийте термінал у папці `Lab10` і виконайте:

```powershell
javac -encoding UTF-8 src/Main.java
java -cp src Main
```

Програму також можна запускати з папки `src`:

```powershell
cd src
javac -encoding UTF-8 Main.java
java Main
```

Під час запуску програма дозволяє змінити один об'єкт, демонструє операції ЛР8-ЛР9, створює двійковий файл і показує відновлений із нього масив.

Приклад даних для інтерактивної зміни:

```text
2
Нова страхова компанія
LIC-NEW-2026
27500000
```
