# Лабораторна робота №5 (ООП в Java) - Програмування Java

## Тема: Класи, об'єкти, методи, пакети, інкапсуляція
## Варіант 14

### Завдання
1. **Теоретична частина (у коментарях до коду `calc/ExpressionCalculator.java`):**
   - Поняття класу і об'єкту.
   - Атрибути і методи класу. Виклик методів.
   - Методи `get` і `set`. Типізовані і безтипові (`void`) методи.
   - Конструктори класу.
   - Перевантаження методів.
   - Поняття статичного атрибуту і методу класу.
   - Поняття пакетів у Java.

2. **Практична частина:**
   - Аргументи (параметри) виразу є атрибутами класу, для кожного реалізовано пару методів `set` та `get`.
   - Аргументи ініціалізуються у конструкторі з параметрами.
   - Реалізовано конструктор за замовчуванням з початковими значеннями.
   - Обчислення виразу здійснюється у нестатичному методі `calculate()` окремого класу.
   - Реалізовано статичний метод `calculateStatic(...)`, який обчислює той самий вираз.
   - Клас із методами обчислення розміщено в окремому пакеті `calc`.
   - Основна програма розміщена в пакеті `mainapp` і демонструє роботу обох конструкторів (створення двох об'єктів), роботу обох методів, циклічні обчислення та обробку виняткових ситуацій введення даних.

### Формула (Варіант 14)
```
R = (sin(x² + 4)³ + 4.3) / sin³(x⁴)
```

### Структура проекту
```
Lab5/

    ├── calc/
    │   └── ExpressionCalculator.java  # Клас з атрибутами, конструкторами, get/set, статичним та нестатичним методами
```

### Запуск програми
У консолі або в IDE (IntelliJ IDEA):
```bash
cd src
javac calc/ExpressionCalculator.java mainapp/Main.java
java mainapp.Main
```
