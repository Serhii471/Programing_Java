# Лабораторна робота №1 — Програмування Java

## Варіант 14

### Завдання
Обчислення і виведення на екран (консоль) значення виразу:

```
R = (sin(x² + 4)³ + 4.3) / sin³(x⁴)
```

Один з аргументів виразу (`x`) вводиться з клавіатури (клас `Scanner`), інші ініціалізовані конкретними значеннями.

### Як запустити

```bash
cd src
javac Main.java
java Main
```
