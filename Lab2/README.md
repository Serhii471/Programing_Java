# Лабораторна робота №2 — Програмування Java

## Варіант 14

### Завдання
1. **Теоретична частина:** Відповіді на запитання щодо логічних операцій та конструкцій розгалуження в Java.
2. **Практична частина:** Доопрацювання програми з ЛР1. Додано перевірку того, чи належать значення змінних області допустимих значень (ОДЗ) виразу. Якщо умова не виконується, програма виводить відповідне повідомлення.

### Формула
```
R = (sin(x² + 4)³ + 4.3) / sin³(x⁴)
```

### Область допустимих значень (ОДЗ)
Знаменник не може дорівнювати нулю, тому:
`sin³(x⁴) ≠ 0`
