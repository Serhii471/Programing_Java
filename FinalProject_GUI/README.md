# FinalProject_GUI - Графічний комплекс лабораторних робіт 1-7

## Опис проекту
Графічний застосунок на Java Swing, що поєднує функціонал усіх 7 лабораторних робіт курсу "Програмування Java" (НУБіП України, Варіант 14):
- Інформаційна картка студента з фотографією (аватаром).
- Інтерактивні обчислення та перевірка ОДЗ (ЛР 1-3).
- Табулювання функцій двома циклами (ЛР 4).
- Робота з класами, інкапсуляція та пакети (ЛР 5).
- Ієрархія класів та агрегація масивів об'єктів (ЛР 6).
- Абстрактні класи, інтерфейси та поліморфізм (ЛР 7).
