## 1. Загальні відомості про варіант №14
У роботах 1–5 досліджується та обчислюється аналітична функція:
$$R = \frac{\sin^3(x^2 + 4) + 4.3}{\sin^3(x^4)}$$

Область допустимих значень (ОДЗ):
$$\sin^3(x^4) \neq 0 \implies x^4 \neq \pi k \implies x \neq \pm \sqrt[4]{\pi k}, \quad k \in \mathbb{Z}$$

У роботах 6–7 реалізовано предметну область згідно з варіантом 14: **"Фінансова установа"**.

## 2. Короткий зміст лабораторних робіт

### Лабораторна робота №1: Базові лінійні обчислення в Java
- **Мета:** Ознайомлення з базовим синтаксисом Java, типами даних `double`, класом стандартного введення `java.util.Scanner` та математичними функціями `java.lang.Math` (`Math.sin`, `Math.pow`).
- **Результат:** Створено консольну програму, що приймає значення $x$ та обчислює $R$.

### Лабораторна робота №2: Розгалуження та контроль ОДЗ
- **Мета:** Застосування умовних операторів `if-else` для перевірки ОДЗ.
- **Особливість реалізації:** Оскільки комп'ютер зберігає дійсні числа `double` у двійковому форматі IEEE 754 з похибкою, порівняння знаменника з нулем виконується через епсилон-окіл: `Math.abs(denominator) < 1e-10`.

### Лабораторна робота №3: Обробка виняткових ситуацій (Exceptions)
- **Мета:** Забезпечення надійності програми за допомогою блоків `try-catch-finally`.
- **Результат:** Перехоплення винятку `InputMismatchException` при введенні текстових символів замість чисел та гарантоване закриття дескриптора `Scanner` у секції `finally`.

### Лабораторна робота №4: Циклічні конструкції (Табулювання)
- **Мета:** Організація повторюваних обчислень за допомогою циклів `for` та `while`.
- **Параметри для N = 14:**
  - Початок діапазону: $X_{start} = -10 - 2.5 \cdot 14 = -45.0$
  - Кінець діапазону: $X_{end} = 5 + 1.2 \cdot 14 = 21.8$
  - Крок аргументу: $\Delta x = 0.5 + 14 / 20 = 1.2$
- **Особливість:** При виявленні точок, де знаменник прямує до 0, виконується оператор `continue` для переходу до наступної точки.

### Лабораторна робота №5: Класи, об'єкти та пакети в Java
- **Мета:** Застосування принципів об'єктно-орієнтованого програмування: інкапсуляція, конструктори, методи доступу.
- **Результат:** 
  - Створено клас `calc.ExpressionCalculator` в окремому пакеті `calc`.
  - Реалізовано конструктор за замовчуванням та конструктор з параметрами (overloading).
  - Реалізовано пари методів `get` / `set`.
  - Розділено обчислення на екземплярний нестатичний метод `calculate()` та утилітарний статичний метод `calculateStatic(...)`.

### Лабораторна робота №6: Успадкування та агрегація
- **Мета:** Побудова ієрархії класів та композиційних зв'язків.
- **Архітектура класів:**
  - `Account` (рахунок): агрегований об'єкт (номер, баланс).
  - `FinancialInstitution` (базовий клас): стан фінансової установи (`name`, `licenseCode`, `baseCapital`), захищені поля `protected`, перевантажені методи `describeActivity(...)`.
  - `Bank` (клас-нащадок): успадковує `FinancialInstitution`, агрегує масив `Account[]`, перевизначає `showInfo()` з викликом `super.showInfo()` та обчислює сумарний баланс клієнтів.

### Лабораторна робота №7: Абстрактні класи та інтерфейси
- **Мета:** Реалізація поліморфізму та кратного спадкування поведінки через інтерфейси.
- **Архітектура:**
  - Інтерфейси: `Auditable` (аудит та податки), `Insurable` (страхування вкладів/ризиків).
  - Абстрактний клас: `FinancialInstitution` визначає абстрактні методи `describeActivity()` та `calculateAnnualRiskReserve()`.
  - Реалізація: класи `Bank` та `InsuranceCompany` одночасно успадковують базовий клас та реалізують контракт `Insurable`.

## 3. Інструкція користувача графічного інтерфейсу (GUI)

Застосунок розроблено на базі бібліотеки **Java Swing** (`javax.swing`). Він об'єднує всі лабораторні роботи в зручному інтерфейсі з вкладками (`JTabbedPane`).

### 3.1. Структура вкладок

1. **Вкладка "Про автора":**
   - Відображає ПІБ автора, назву університету, дисципліну та номер варіанту.
   - Відображає фотокартку автора. Якщо користувач бажає завантажити власне реальне фото, достатньо помістити файл із назвою `author.png` у каталог `src/resources/`. Якщо файл відсутній, програма генерує векторний аватар-заглушку.
   - Містить опис усіх інтегрованих лабораторних робіт.

2. **Вкладка "ЛР 1-3: Обчислення виразу":**
   - Дозволяє ввести довільне значення аргументу $x$ у текстове поле.
   - При натисканні на кнопку **"Обчислити R"**:
     - Здійснюється перевірка валідності введеного числа (якщо введено некоректний символ — спрацьовує перехоплення `try-catch`).
     - Перевіряється умова ОДЗ ($\sin^3(x^4) \neq 0$).
     - У консольне поле виводиться докладне значення чисельника, знаменника та підсумковий результат $R$.

3. **Вкладка "ЛР 4: Цикли (Табулювання)":**
   - Дозволяє задати номер варіанту $N$ (за замовчуванням 14).
   - При натисканні на **"Табулювати (for & while)"** генерується порівняльна таблиця значень функції на відрізку $[-45.0; 21.8]$ з кроком $1.2$, обчислена незалежно двома циклами.

4. **Вкладка "ЛР 5: ООП & Методи":**
   - Демонструє створення двох об'єктів `calc.ExpressionCalculator` (через конструктор за замовчуванням та з параметрами).
   - Демонструє модифікацію полів через сетери та порівнює виклик нестатичного методу екземпляра зі статичним методом класу.

5. **Вкладка "ЛР 6: Успадкування & Агрегація":**
   - Ілюструє роботу агрегованого масиву `Account[]` всередині банку `Bank`.
   - Показує виклик перевизначених методів `showInfo()`, `describeActivity()` та розрахунок сумарного балансу.

6. **Вкладка "ЛР 7: Абстракція & Інтерфейси":**
   - Демонструє динамічний поліморфізм при обході масиву об'єктів через абстрактний тип `FinancialInstitution[]`.
   - Демонструє роботу об'єктів через інтерфейс `Insurable[]`.

### 3.2. Запуск програми

#### Варіант 1: Запуск в IDE (IntelliJ IDEA / Eclipse / NetBeans)
1. Відкрити папку `FinalProject_GUI` як Java-проєкт.
2. Встановити теку `src` як папку з вихідним кодом (Mark Directory as Sources Root).
3. Відкрити файл `src/gui/MainApp.java` і натиснути **Run** (зелений трикутник).

#### Варіант 2: Запуск через термінал
```bash
cd FinalProject_GUI/src
javac calc/ExpressionCalculator.java gui/MainApp.java
java gui.MainApp
```
