# Другий модуль: об'єднаний GUI-проєкт ЛР8-ЛР11

## Дисципліна: Програмування Java
## Варіант 14: Фінансова установа

Проєкт об'єднує лабораторні роботи другого модуля в одному Java Swing застосунку.

## Вкладки програми

### ЛР8 - Масив об'єктів

- агрегований масив із 10 фінансових установ;
- перегляд і редагування вибраного об'єкта;
- фільтрація за мінімальним капіталом;
- сортування капіталу за зростанням і спаданням.

### ЛР9 - Текст і пошук

- сортування українських назв у двох напрямках;
- вибірка за регулярним виразом;
- пошук установ із мінімальним і максимальним капіталом.

### ЛР10 - Файли

- зчитування UTF-8 файла `data/institutions.txt`;
- запис відсортованого масиву в `data/institutions.dat`;
- відновлення масиву з двійкового файла.

### ЛР11 - SQLite JDBC

- перегляд таблиці БД;
- додавання, редагування та видалення записів;
- параметризована вибірка за мінімальним капіталом;
- автоматичне створення схеми з первинним ключем, `UNIQUE`, `NOT NULL` і `CHECK`.

## Запуск

З кореня репозиторію `Programing_Java`:

```powershell
.\Module2_GUI\run.bat
```

Або з папки проєкту:

```powershell
.\run.bat
```

## Автоматична перевірка

```powershell
.\verify.bat
```

Успішний результат:

```text
MODULE2_GUI_VERIFICATION_PASSED
```

## API-документація

Усі класи та методи мають Javadoc-коментарі. Готова HTML-документація знаходиться у `docs/api/index.html`.

Для повторної генерації:

```powershell
.\generate-docs.bat
```

Параметр `-private` включає до документації публічні та внутрішні методи GUI.

## Структура

```text
Module2_GUI/
├── data/                 - початковий TXT і робочі файли
├── docs/api/             - згенерована Javadoc документація
├── lib/                  - SQLite JDBC 3.53.4.0
├── src/                  - Java-код за пакетами model/service/io/db/ui
├── build.bat             - компіляція
├── run.bat               - запуск GUI
├── verify.bat            - інтеграційна перевірка
└── generate-docs.bat     - повторна генерація API
```
