# Лабораторна робота №4 - Програмування Java

## Тема: Циклічні конструкції
## Варіант 14

### Завдання
1. Переробити попередню лабораторну роботу.
2. Обчислити і вивести значення виразу для всіх `x` з діапазону `[-10 - 2.5N; 5 + 1.2N]`, з кроком `Δx = 0.5 + N/20`, де `N` - номер вашого варіанту.
3. Задачу виконати двома способами: за допомогою циклу `for` і циклу `while`.
4. Має бути реалізовано обробку виняткової ситуації некоректного введення значення змінної на вході (обробка введення номеру варіанту).
5. У циклі має перевірятися, чи задовольняють аргументи область допустимих значень (ОДЗ). Якщо не задовольняють, має бути перехід на наступну ітерацію циклу (`continue`).
