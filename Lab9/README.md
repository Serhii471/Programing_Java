# Лабораторна робота №9 - Програмування Java

## Тема: Сортування, регулярні вирази та пошук екстремальних значень
## Варіант 14: Фінансова установа

---

## 1. Завдання

Програму з ЛР8 доповнено можливостями:

1. сортування масиву фінансових установ за зростанням і спаданням текстового поля `name`;
2. пошуку установ, текстове поле яких задовольняє регулярному виразу;
3. визначення установ із найменшим і найбільшим значенням числового поля `baseCapital`.

Попередні можливості ЛР8 збережено: ініціалізація масиву з 10 об'єктів, виведення, зміна вибраного елемента, числова фільтрація та сортування за капіталом.

---

## 2. Реалізація нових операцій

### 2.1. Сортування текстового поля

Методи `sortByNameAscending()` і `sortByNameDescending()` сортують установи за назвою. Для правильного порівняння українських літер використано `Collator` з локаллю `uk-UA`.

### 2.2. Умова для текстового поля

Самостійно сформульована умова: **назва фінансової установи закінчується словом «Банк» без урахування регістру**.

Регулярний вираз:

```text
.*банк$
```

Пошук виконує метод `printMatchingName(...)` за допомогою класів `Pattern` і `Matcher`.

### 2.3. Найменше і найбільше числове значення

Метод `printCapitalExtremes()` одним проходом масиву знаходить установи з мінімальним і максимальним базовим капіталом та виводить повідомлення такого виду:

```text
Найменший базовий капітал 4 800 000,00 грн має установа "Кредитна спілка Добробут",
найбільший - 41 000 000,00 грн - має установа "Український Розвиток Банк".
```

## 3. Запуск програми

Відкрийте термінал у папці `Lab9` і виконайте:

```powershell
cd src
javac -encoding UTF-8 Main.java
java Main
```

Приклад даних для перевірки модифікації:

```text
2
Нова страхова компанія
LIC-NEW-2026
27500000
```

Після введення програма послідовно продемонструє всі операції ЛР8 та нові операції ЛР9.
